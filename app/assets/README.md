# Optional reference assets

The pipeline works without any of these files. Adding them makes the generated photos closer to your real products.
They are not in the repository because they are usually your own product photos.

| Path | Used for |
|---|---|
| `long_cap_shape.jpg` | Photo of your long-hair cap: shape reference for on-model photos |
| `kit_bag.jpg`, `kit_accessories.jpg` | Your packaging / accessories for the "what's in the box" shot |
| `pose_refs/stretch_1.jpg` … `stretch_5.jpg`, `puton_1.jpg`, `puton_2.jpg` | Real photos of hands stretching / putting on a cap (poses in `app/config.json`) |
| `pu_refs/*.png` | 1–3 examples of your PU prints: style reference for PU generation |
| `examples/<pose id>.jpg` | Example thumbnails shown on the shot-type tiles in the UI |
