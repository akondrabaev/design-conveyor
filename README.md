# Design Conveyor

**AI-конвейер дизайна принтов для силиконовых и PU-шапочек для плавания: от идеи до файлов для фабрики и фото для маркетплейса.**

*English summary: a local web app that turns a text idea into a production-ready swim-cap print — screen-print stencils (≤ 3 inks, RAL Classic colours), flat layouts, mockups in several colourways and a bilingual (EN / 中文) Excel tech pack — and then generates consistent lifestyle photos of the cap on recurring AI models. Built on Google Gemini, Python, FastAPI and a vanilla-JS UI.*

---

## Что это

Design Conveyor — локальное веб-приложение для бренда, который выпускает шапочки для плавания. Оно закрывает путь от «хочу детскую шапочку с акулой» до:

- **файлов для производства** — векторные трафареты на каждую краску (SVG / PNG), раскладка на шаблоне шапочки с зоной печати, полноцветный файл 300 dpi для PU;
- **технического задания** в Excel на английском и китайском: цвета шапочки и красок в палитре RAL Classic, размеры, параметры печати, автопроверки, мокапы;
- **визуала для продаж** — мокапы во всех колорамах и фото «шапочка на человеке» с постоянными ИИ-моделями, предметная съёмка, слайд комплектации;
- **каталога**: из готовых трафаретов без ИИ собираются новые модели (другая форма шапочки, другие цвета), всё выгружается пакетом в папку или Excel.

Всё работает на одном компьютере, данные хранятся в файлах рядом с приложением.

## Возможности

| Раздел | Что делает |
|---|---|
| **1. Новинки** | Тема + референсы (до 4 картинок) + пресет сегмента + форма шапочки → Gemini придумывает концепцию и палитру, рисует принт; движок сводит его к ≤ 3 краскам, векторизует, режет трафареты, собирает раскладку, мокап и ТЗ. |
| **2. Модели и ракурсы** | Постоянные ИИ-модели (по группам: женщины, мужчины, девочки, мальчики) с эталоном лица; листы ракурсов (безликий манекен 5×2), нарезаемые на позы. Модели можно добавлять, редактировать, удалять. |
| **3. Фото на моделях** | Модели × ракурсы × сцены → фото 3:4, 2K. Принт ложится с учётом поворота головы (3D-гайд размещения), лицо сохраняется по эталону, каждый кадр проверяет Gemini-vision и перегенерирует при ошибках. Плюс «тянет шапочку», предметная съёмка, комплектация. |
| **4. Конструктор** | Новая модель без ИИ: трафареты любого дизайна + другая форма шапочки + свои цвета RAL (до 3 колорам, у каждой свои краски) с мгновенным превью. Для PU — свой принт (загрузка картинки), положение и размер мышью, логотип (вектор или стилизованный под принт ИИ). |
| **5. Выгрузка** | Галочками выбрать модели → Excel «одна строка = один цвет с принтом» (картинки в полном разрешении) или «Сохранить как…»: папка с Excel и подпапкой на модель (мокап, ТЗ, SVG, PNG, колорамы). |

**Формы шапочек:** стандартная (взрослая / детская), для длинных волос, детские фигурные (рожки, острые ушки, круглые ушки, рыбка, гребень дракона), PU детская и взрослая.

**Печать:**
- силикон — трафарет, ≤ 3 краски, зазор между красками, минимальная толщина линии, отступ от края; фигурные шапочки печатаются по всему контуру, включая литые детали;
- PU — полноцветный термоперенос: «персонаж с логотипом» или «на всю шапочку» без фона, с зазором от края.

**Цвет:** палитра дизайна сразу подгоняется под RAL Classic (192 цвета, ΔE2000); краски каждого варианта шапочки подбираются так, чтобы оставаться читаемыми (ΔE ≥ 30 к цвету шапочки).

## Как это устроено

```
 Браузер (vanilla JS, app/static)
     │  REST + фоновые задачи (poll)
     ▼
 FastAPI  app/server.py ──────────────┐
     │                                │ запускает подпроцессы
     ├─ app/catalog.py   каталог, мокапы, удаление
     ├─ app/content.py   ИИ-модели, ракурсы, фото на моделях, проверка кадров
     ├─ app/guide.py     3D-гайд: развёртка принта на голову манекена под углом позы
     └─ lib/compose.py   конструктор (без ИИ)
                                       ▼
 tools/generate.py ─► lib/gemini_gen.py   арт-дирекция (JSON) → картинка → сведение к краскам (Lab)
                      lib/shape_canvas.py фигурные шапочки: рисование на силуэте, проверка симметрии
                      lib/gemini_design.py маски красок → вектор (potrace) → шаблон шапочки
                      lib/build.py, core.py зона печати, зазоры, трафареты, раскладка, мокап (shapely)
                      lib/spec_xlsx.py    ТЗ в Excel (EN / 中文)
 tools/generate_pu.py ─► полноцветный PU-принт, вырезка фона, размещение (lib/pu.py)
```

**Поток данных одной новинки:**

1. **Арт-дирекция** (текстовая модель) — JSON: название, концепция, сегмент, цвет шапочки + варианты, 2–3 краски, промпт картинки. Палитра сразу переводится в RAL.
2. **Картинка** (image-модель) — плоский принт только этими цветами; фигурные шапочки рисуются прямо на силуэте.
3. **Сведение к краскам** — ближайший цвет в Lab, удаление элементов тоньше минимальной толщины.
4. **Вектор и движок** — трассировка potrace, обрезка по зоне печати, вырез под логотип, технологический зазор между красками, проверки.
5. **Экспорт** — `designs/<slug>/`: мокап и ТЗ в корне, `SVG/` и `PNG/` с принтом, трафаретами и раскладками, исходники модели в `_gemini/`.

**Хранение:** всё — файлы (`designs/`, `packs/`, `personas/`, `poses/`, `uploads/`). Базы данных нет; задачи выполняются в фоновых потоках, лог виден в интерфейсе.

**Бренд** — настройка `BRAND_NAME`. В коде и промптах используется нейтральный токен `BRAND`; перед отправкой в модель он заменяется на ваше название, в том числе буквы надписи (`A-C-M-E`). Логотип — векторные файлы `lib/logo_*.txt`.

## Стек

- **Python 3.10+**: FastAPI, Uvicorn, Pillow, NumPy, SciPy, OpenCV (headless), Shapely, potracer, openpyxl, CairoSVG / resvg-py (рендер SVG, на Windows — resvg).
- **Google Gemini** через `google-genai`: текстовая модель (арт-дирекция, проверки, переводы) и image-модель (принты, фото). Модели переопределяются переменными окружения.
- **Фронтенд**: одна страница на vanilla JS без сборки; «Сохранить как…» использует File System Access API (Chrome / Edge), в других браузерах — ZIP.
- **Опционально**: Cloudflare Worker-ретранслятор для серверов в регионах, где Gemini API недоступен (`deploy/gemini-relay/`).

## Установка

Нужны Python 3.10+ и **платный** ключ Google Gemini API (на бесплатном уровне нет квоты на генерацию картинок).

```bash
git clone https://github.com/akondrabaev/design-conveyor.git
cd design-conveyor
cp .env.example .env          # вписать GEMINI_API_KEY и BRAND_NAME
```

**Windows:** двойной клик по `start.bat` — создаст `.venv`, поставит зависимости и откроет http://localhost:8765.

**Linux / macOS:**

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python -X utf8 -m uvicorn server:app --app-dir app --host 127.0.0.1 --port 8765
```

На Linux для CairoSVG нужна системная библиотека cairo (`apt install libcairo2`); без неё используется resvg.

### Первый запуск

1. **Логотип.** `python tools/make_logo.py my_logo.png adult` (и `kids` — для детских шапочек) создаёт `lib/logo_*.txt` из вашего логотипа. В репозитории лежит заглушка «BRAND».
2. **Модели и ракурсы.** Во вкладке «Модели и ракурсы» сгенерируйте эталоны ИИ-моделей (или загрузите фото своих моделей с их согласия) и листы ракурсов для каждой группы.
3. **Новинка.** Вкладка «Новинки»: тема, пресет, форма шапочки → «Сгенерировать дизайн» (1–3 минуты).
4. По желанию положите свои фото-референсы в `app/assets/` (см. [app/assets/README.md](app/assets/README.md)).

### Настройка под производство

- **Размеры шапочек** — `lib/shapes.py: SIZES` (ширина, высота, ширина низа, вес). Масштаб принта в мм и таблица размеров в ТЗ считаются от них.
- **Силуэты** — `lib/cap_*.txt` (SVG path, тело шапочки 1000 px по ширине). Замените на точные выкройки вашей фабрики; `lib/trace_shapes.py` обводит контур с изображения в `lib/shape_src/`.
- **Технология** — `lib/core.py`: `GAP` (зазор между красками), `MINW` (минимальная толщина), `MARGIN` (отступ от края); `lib/pu.py: GAP` — зазор PU-принта.
- **Пресеты сегментов** — `tools/presets.py`; **модели, ракурсы, сцены** — `app/config.json`; **лимит хранилища** — `storage_limit_gb` там же.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `GEMINI_API_KEY` | Ключ Gemini API (обязательно) |
| `BRAND_NAME` | Название бренда для промптов, ТЗ, файлов и интерфейса |
| `GEMINI_TEXT_MODEL`, `GEMINI_IMAGE_MODEL` | Переопределение моделей |
| `GEMINI_BASE_URL`, `RELAY_SECRET` | Запросы к Gemini через ретранслятор (`deploy/gemini-relay/`) |

## Развёртывание на сервере

Приложение рассчитано на локальную работу. Для команды:

- **Ресурсы:** 1 vCPU / 2 ГБ RAM / 40 ГБ SSD + своп 2 ГБ хватает 1–2 пользователям (пик сборки дизайна ~0,7 ГБ, генерация — ожидание ответа Gemini); 2 vCPU / 4 ГБ — для нескольких параллельных задач.
- **Обязательно закройте доступ:** у интерфейса нет авторизации, открытый в интернет он позволит тратить ваш ключ Gemini. Поставьте nginx с basic auth / SSO и HTTPS, uvicorn оставьте на 127.0.0.1.
- **Регионы без доступа к Gemini:** Cloudflare Worker из `deploy/gemini-relay/` (с секретным заголовком и Smart Placement) или HTTPS-прокси через `HTTPS_PROXY`. Проверка: `deploy/gemini-relay/relay_test.py`.
- Запуск как сервиса — systemd unit с командой uvicorn из раздела «Установка».

## Структура проекта

```
app/            веб-приложение: server.py (API), catalog.py, content.py, guide.py, config.json, static/ (UI)
lib/            движок: генерация, сведение красок, вектор, трафареты, ТЗ, RAL, формы шапочек, конструктор, выгрузка
tools/          CLI: generate.py, generate_pu.py, recolor.py, mirror_b.py, migrate_designs.py, make_logo.py, on_model.py
deploy/         ретранслятор Gemini на Cloudflare Workers
run_gemini.py   сборка одного дизайна (в том числе повторная, без вызова модели)
```

Создаются при работе (в git не попадают): `designs/` — дизайны, `packs/` — фотосессии, `personas/` — ИИ-модели, `poses/` — ракурсы, `uploads/` — загрузки и пакеты выгрузки.

### CLI

```bash
python tools/generate.py --preset kids --shape kid_dragon --mirror-b --slug kids_shark --theme "a funny shark with a toothy smile"
python tools/generate_pu.py --shape pu_kids --layout allover --slug pu_reef --theme "happy sea creatures"
python run_gemini.py --spec designs/<slug>/_gemini/spec.json --raw-A designs/<slug>/_gemini/side-A_raw.png   # пересборка без ИИ
python tools/migrate_designs.py [slug ...]      # пересобрать дизайны в текущий формат
```

## Ограничения

- Фото на моделях — иллюстрация: модель перерисовывает принт приблизительно. Печатать нужно по трафаретам, а не по фото.
- Цвета на экране приблизительные: утверждайте шапочку и краски по физическим образцам RAL.
- Проверка на оригинальность (чужие персонажи, логотипы) — запрет в промптах и глаз человека; автоматической проверки нет.
- Силуэты и размеры в репозитории — шаблоны: перед запуском в производство замените их данными своей фабрики.
